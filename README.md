# IoT Sensor Dashboard

## 프로젝트 개요

teros11센서와 아두이노로 수집한 센서값을 
라즈베리파이 내에서 PHP와 MariaDB를 활용하여 센서 데이터를 웹에서 조회하고 시각화하는 대시보드 구축


## 주요 기능

- **센서 데이터 조회**: 데이터베이스에 저장된 ID, 날짜, 토양 수분, 온도, 상태 정보 표시
- **그래프 시각화**: 토양 수분 및 온도 데이터를 선 그래프로 표현
- **이미지 조회**: 데이터에 연결된 이미지 표시 및 이미지 열기
- **비동기 데이터 요청**: jQuery AJAX를 활용하여 PHP 서버에 데이터를 요청하고 화면 갱신
- **데이터베이스 연동**: PHP의 MySQLi를 활용하여 MariaDB 조회 결과를 JSON 형식으로 반환

## 기술 스택

| 구분 | 기술 |
|---|---|
| Backend | PHP |
| Database | MariaDB |
| Frontend | HTML, CSS, JavaScript |
| 비동기 통신 | jQuery AJAX |
| 데이터 시각화 | Chart.js |


## 구현 내용

### 1. 데이터베이스 연동

- PHP MySQLi를 사용하여 MariaDB에 연결함.
- `sensor` 테이블에서 센서 데이터를 조회함.
- 조회 결과를 JSON 형식으로 변환하여 클라이언트에 전달함.

### 2. 센서 데이터 대시보드

- AJAX 요청으로 센서 데이터를 가져옴.
- 조회된 데이터를 HTML 테이블에 표시함.
- 토양 수분, 온도 및 센서 상태를 한 화면에서 확인하도록 구성함.

### 3. 그래프 시각화

- Chart.js를 활용하여 토양 수분과 온도를 각각 선 그래프로 표현함.
- 데이터의 날짜를 그래프의 가로축 레이블로 사용함.
- 서버에서 전달받은 데이터로 그래프를 갱신하도록 구현함.

### 4. 이미지 조회

- 데이터베이스의 이미지 URL을 활용하여 이미지 목록을 표시함.
- 이미지와 관련된 ID, 날짜 및 URL 정보를 함께 표시함.
- 이미지를 클릭하면 별도 창으로 열도록 구현함.

## 실행 환경 및 설정

1. PHP 실행 환경과 MariaDB를 준비함.
2. `dataDB` 데이터베이스와 `sensor` 테이블을 구성함.
3. `db_config.php`에서 데이터베이스 호스트, 계정, 비밀번호 및 데이터베이스명을 환경에 맞게 설정함.
4. 프로젝트 파일을 PHP 웹 서버의 실행 경로에 배치함.
5. 브라우저에서 `index.php`에 접근하여 대시보드를 확인함.

## 학습 내용

- PHP와 MariaDB 간 데이터베이스 연결 및 조회
- 서버에서 조회한 데이터를 JSON으로 반환하는 방법
- jQuery AJAX를 활용한 클라이언트-서버 간 비동기 통신
- Chart.js를 활용한 데이터 시각화
- HTML, CSS, JavaScript를 활용한 대시보드 UI 구성

## 참고 사항

- 현재 코드는 데이터베이스에 저장된 센서 데이터를 조회하고 화면에 표시하는 부분을 중심으로 구성되어 있음.
- 실제 센서의 데이터 수집 및 데이터베이스 저장 과정은 별도로 구성해야 함.
- 데이터베이스 연결 정보와 실행 환경은 사용하는 서버에 맞게 수정해야 함.
- 반복적인 AJAX 요청 방식과 데이터베이스 연결 설정은 실제 운영 환경에 적용하기 전에 개선 필요.
